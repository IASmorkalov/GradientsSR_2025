# GradientsSR_2025
Soil respiration in pollution gradients in 2025
This repository contains aggregated data in-situ soil respiration of forests at the two pollution gradients in 2025 and scripts for it analisys.

If you have any questions related to these data, feel free to contact me by email at ivan.a.smorkalov@gmail.com.
